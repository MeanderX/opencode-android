OpenCode on Android

The full OpenCode 2 agent, running on the phone in your pocket. No root, no computer, no cloud container. Two steps and one paste.

1

Install Termux

Use F-Droid or the GitHub release. The Play Store build is outdated and does not work.

Get Termux (F-Droid) GitHub release
2

Copy the installer

Open Termux, paste this, press enter. It downloads the project and runs the setup.

pkg install -y git && git clone --depth 1 https://github.com/MeanderX/opencode-android ~/opencode-android && bash ~/opencode-android/install.sh
Open Termux

First run downloads a few hundred MB and takes 5–15 minutes. Approve the storage dialog if it appears.

3

Start coding

Type oc in Termux. Sign in to a model provider on first launch. Optional: install Termux:Widget to put OpenCode on your home screen.

Share it. Scan this with another Android phone to open this page. Works from any camera app.
